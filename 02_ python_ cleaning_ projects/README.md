# Student Dataset Cleaning and Standardization Using Python

## Project Overview

This project demonstrates the use of Python and Pandas to inspect, clean, and standardize a small student dataset.

The original dataset contained missing values, duplicate records, and inconsistent department names. The goal was to identify these data-quality problems and apply appropriate cleaning techniques without introducing inaccurate information.

## Tools Used

- Python
- Pandas
- Microsoft Excel
- CSV
